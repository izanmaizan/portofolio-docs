# Portofolio Pribadi

Situs portofolio pribadi yang menyajikan profil, pengalaman, dan proyek dalam satu halaman statis.

## Kegunaan

- Menampilkan profil, keahlian, pengalaman kerja, dan proyek.
- Menjadi halaman rujukan untuk lamaran kerja dan kontak profesional.

## Tech stack

| Lapis | Teknologi |
|---|---|
| Framework | Astro 5 |
| UI | React 19, Tailwind CSS, Framer Motion |
| Deploy | Vercel |

## Alur singkat

1. Konten ditulis sebagai data di repo.
2. Astro membangun halaman statis saat build.
3. Hasil build dideploy ke Vercel.
